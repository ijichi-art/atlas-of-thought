Atlas of Thought turns the linear scroll of your ChatGPT / Claude / Gemini
history into a **living geographic map**:

- **Countries** for big themes ("Health & Nutrition", "Software & Tools")
- **Cities** for individual idea-clusters
- **POIs** for each conversation — click to read the original chat
- **Highways** between cities that share strong semantic links
- **Rivers, bridges, interchanges** generated by procedural cartography

Built on real urban-planning math: Euclidean MST + Delaunay
triangulation for road planarity, FHWA-inspired tier hierarchy, density
thresholds for built-up areas, Voronoi-clipped street grids per cluster.

It's **OSS, local-first, BYOK** (Bring Your Own Key). Your chat history
never leaves your machine.

## Why?

Today's AI chat UIs are linear. You scroll, you search, you forget. The
networks of ideas you built across dozens of sessions get lost in the
timeline. Atlas of Thought treats your conversations as **terrain**: the
human brain remembers space far better than text.

Other tools (ChatGPT-2D, ChatMap, Obsidian Canvas) stop at node-link
diagrams or require manual layout. Atlas of Thought generates a **real
geographic map** automatically — countries, cities, roads, rivers — from
the shape of what you've discussed.

## Download (desktop app)

When a `v*.*.*` git tag is pushed, GitHub Actions builds **unsigned**
Mac / Windows / Linux installers and attaches them to a GitHub release.
First launch (one extra click, once):

- **macOS**: right-click the app → *Open* → confirm
- **Windows**: when SmartScreen warns, click *More info* → *Run anyway*
- **Linux**: AppImage may need `chmod +x` first

After install: open the app → paste your LLM API key in Settings →
import a chat export → click *Terraform*.

## Quick start (Solo mode, ~5 minutes from source)

Run from source if you want to hack on it or your platform isn't built
yet. SQLite, no Postgres, no Docker, no GitHub OAuth.

**Prerequisites:** Node 20+ (or 22+).

```bash
git clone https://github.com/ijichi-art/atlas-of-thought.git
cd atlas-of-thought
npm install
cp .env.example .env.local

# Generate one secret (encryption key for your stored API key):
echo "ENCRYPTION_KEY=\"$(openssl rand -base64 32)\"" >> .env.local

# Create the local SQLite database:
npx prisma db push

# Start:
npm run dev
```

Open <http://localhost:3002> → Settings → paste your LLM API key (DeepSeek
$0.30 per 1500-conversation map, OpenAI ~$3, Anthropic ~$5–15 depending
on model) → Import → Terraform.

That's it. The map lives in `prisma/dev.db` on your machine.

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind 4 · Prisma + SQLite
(via better-sqlite3) · D3-force / D3-delaunay · Anthropic SDK · OpenAI
SDK · DeepSeek API · Framer Motion.

## Architecture (one paragraph)

The pipeline runs in three stages: (1) **Cartographer LLM** reads each
conversation and assigns it to a country / district / city, emitting a
deterministic JSON cluster tree; (2) **Force layout** places clusters in
2D using d3-force with link forces from semantic edges; (3) **Procedural
generation** lays a Euclidean MST through Delaunay triangulation (planar
road network, no crossings), adds 5 detour-shortcut bypass highways,
generates one major river per map, scatters POIs with center-biased
density, and seeds each cluster's built-up polygon with building
footprints + rotated street grid clipped to its Voronoi cell.

Result: a map that looks like a real city, where adjacency = semantic
similarity and roads connect topics that recur together.

## BYOK (Bring Your Own Key)

You supply your own LLM API key. Supported providers:

| Provider | Cheapest model for terraform | ~Cost per 1500-conversation map |
|---|---|---|
| **DeepSeek** | `deepseek-chat` (V3) | **~$0.30** |
| **OpenAI** | `gpt-4o-mini` | ~$0.50 |
| **Anthropic** | `claude-haiku-4-5` | ~$3 |

Get a key at the provider's console (links in the in-app Settings page).
Your key is encrypted with AES-256-GCM using `ENCRYPTION_KEY` from your
`.env.local` and stored locally in SQLite. **It never leaves your
machine** except as outbound HTTPS to the provider you chose.

> ⚠️ Rotating `ENCRYPTION_KEY` invalidates the stored API key — keep
> the value backed up somewhere if you'll move the DB between machines.

## Privacy

- **Local-first by design.** All conversations and the generated map
  live in `prisma/dev.db` on your machine.
- **No telemetry, no analytics.** The app makes outbound HTTPS only
  when you click *Terraform* (to your chosen LLM provider) or browse
  share URLs (Phase 5+, opt-in).
- **No central server.** There's no atlas-of-thought.com that holds
  your data. The future *Publish snapshot* feature uploads a single
  static render of a map you choose — never the underlying chat data.
- **Importer parses files locally.** Your ChatGPT export zip is read
  in the Node process; nothing about the contents is sent anywhere
  except the cartographer LLM call you initiate.
